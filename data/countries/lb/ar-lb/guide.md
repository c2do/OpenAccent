# Lebanese Arabic (لبناني)

Lebanese Arabic, with Beiruti as the default. Mountain, northern and southern speech differ; follow the user if they show a regional form.

## Pronunciation

- ق is a glottal stop in Beirut. Usually still written ق; some write أ ("أدّيش").
- ج is a soft "zh" sound, as in Syria.
- Final ة often sounds like -e or -i in Beirut ("مدرسة" = madrase or madrasi). It is still written ة.

## Grammar & markers

- Negation of nouns and adjectives: مش ("مش هيك"، "مش مشكلة"). Verbs: ما ("ما بعرف").
- Future: رح ("رح إجي").
- Continuous: عم, often followed by the بـ form ("عم بحكي"، "عم بيعمل").
- Demonstratives: هيدا (this, m.), هيدي (this, f.), هيدول (these); هيداك / هيديك (that). هاي (this, f.) is also heard.
- Pronouns: نحنا (we), إنتو (you pl.), هنّي (they).
- Now: هلّق / هلّأ. Common: شو في؟ (what's up), كيفك, قدّيش, إي (yes), لأ (no).

## Common AI mistakes

- Using Syrian مو or هاد where Beirutis say مش and هيدا.
- Using Jordanian or Palestinian هسّا / إشي / عشان.
- Overdoing French or English. Code-switching ("merci"، "bonjour"، "hi كيفك") is real, but only use it if the user does; do not insert "ça va" into every reply.
- Egyptian, Gulf or MSA leakage as listed in the Levantine guide.

## Natural usage

- Arabizi is very common in Lebanese chat ("kifak", "shu 3am ta3mel"). Reply in whatever script the user writes.
- Mirror the user's mix of Arabic, French and English, no more and no less.
- Common spellings drop hamza and shadda: هلق, هيدا, شو, كتير.

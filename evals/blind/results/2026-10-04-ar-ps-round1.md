# Blind test, round 1: Palestinian (ar-ps), 2026-10-04

**Setup.** 10 questions from `questions/ar-levantine.yaml`, asked in ChatGPT twice: without and with the paste-in prompt from `docs/prompts/ar-ps.md`. The pairs were shuffled into A/B with a hidden key and judged by ChatGPT in a separate chat (not by native-speaker judges yet).

**Result (after decoding the key).**

| | Pairs |
|---|---|
| Judge preferred the reply **with** the prompt | 1 (q02) |
| Judge preferred the reply **without** it | 1 (q03) |
| Same | 8 |
| Naturalness total (1–5 per reply) | with 41, without 42 |

MSA the judge found was rare and on both sides (without: «فقط»; with: «خصوصًا», «تحرس أحلامه»).

**Verdict: no measurable difference.** The prompt did not win any kind of question (the threshold is 60% of decided pairs).

**Why this round can't say more.**
- **Contaminated baseline.** ChatGPT's memory was on in the test chats (temporary chats were used, but the judge chat disclosed that memory knew the user's city and Palestinian style). One "without" reply mentioned the user's city unprompted. Contamination makes the baseline look better, so it biases against the prompt, not for it.
- **Easy questions.** Greetings, invitations, apologies and jokes use shared colloquial Arabic that a good model already handles. The judge called most items low-discrimination.
- **A model judging a model.** No native-speaker judges yet.

**What it does tell us.** For general Palestinian/Levantine, when the user already writes in the dialect, ChatGPT stays in it without help. This matches the strategy review's warning: same-dialect chat is not where OpenAccent can show value.

**Round 2 (planned).** One named village dialect; ChatGPT memory off in settings (or a fresh account); at least one native-speaker judge from that area; questions that target the judge's own self-reported weaknesses: village-specific words, ق/ك writing, negation, a long chat mixing English and technical terms, and switching register (grandmother, friend, customer) without changing dialect.

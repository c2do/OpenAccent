# الاختبار الأعمى: هل النص الجاهز بيفرق فعلاً؟

هاد الاختبار هو اللي بيقرر إذا OpenAccent بيستاهل نكمل فيه بهالشكل. ناس من أهل اللهجة بيحكموا، مش سكربت.

## الخطوات

1. `npm run blind -- --new ar-levantine` بيعمل مجلد فيه `answers.md`: الأسئلة والخطوات.
2. اسأل كل سؤال **مرتين** بنفس التطبيق ونفس النموذج، كل مرة بمحادثة جديدة والذاكرة مطفية:
   - **بدون:** بلا أي تعليمات.
   - **مع:** بعد ما تلصق النص من [`docs/prompts`](../../docs/prompts/README.md) في التعليمات المخصّصة.
   الصق الردود بأماكنها.
3. `npm run blind -- --sheet evals/blind/<المجلد>` بيعمل `judge-sheet.md`: لكل سؤال ردّين بترتيب عشوائي، بدون ما يبيّن مين مين. **لا تفرجي حدا `key.json`.**
4. اعمل نسخة من الورقة لكل حَكَم (`judge-<اسم>.md`). كل واحد بيكتب `1` أو `2` أو `=`. الأحسن حَكَمين كبروا وهم بيحكوا اللهجة، وما بيعرفوا شو منتظرين.
5. `npm run blind -- --score evals/blind/<المجلد>` بيطلع النتيجة لكل نوع سؤال (بنفس اللهجة، من الإنجليزي، محادثة طويلة).

## شو بتعني النتيجة

- النص "بيربح" نوع أسئلة إذا الحكّام فضّلوه بـ **60% أو أكثر** من الأزواج اللي فيها قرار.
- إذا ما ربح بولا نوع: بنغيّر التوجّه (شوف قسم 7 بتقرير الاستراتيجية).
- انشر الأزواج الخام مع النتيجة، حتى لو كانت النتيجة مش لصالحنا.
